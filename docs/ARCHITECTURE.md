# معماری و راهنمای جامع پروژه Nora (Tauri 2.0 Boilerplate)

## ۱. هدف و چشم‌انداز
پروژه **Nora** یک بستر (Boilerplate) ماژولار، مدرن و با عملکرد بالا بر پایه **Tauri 2.0** برای ویندوز است. هدف این بستر فراهم آوردن زیرساختی پایدار است تا بتوان با حداقل تغییرات، **ده‌ها نرم‌افزار دسکتاپ مستقل** بر روی آن ایجاد کرد.

---

## ۲. پشته فنی (Tech Stack)

| لایه | فناوری / ابزار | کاربرد |
|---|---|---|
| **هسته دسکتاپ (Backend)** | Tauri 2.0 (Rust) | امنیت بالا، IPC سریع، مصرف حداقل رم و دسترسی بومی به ویندوز |
| **ارتباط سخت‌افزاری** | Rust Serialport / Raw WinAPIs | پورت‌های سریال (COM)، پرینترها، بارکدخوان، آردوینو |
| **رابط کاربری (Frontend)** | React 18+ / TypeScript / Vite | فریم‌ورک کامپوننت‌محور با عملکرد بالا |
| **استایل و پوسته** | Tailwind CSS + Shadcn UI + Lucide | تم دارک پیش‌فرض + پشتیبانی دو زبانه (EN چپ‌چین / FA راست‌چین) |
| **مدیریت وضعیت** | Zustand | مدیریت تنظیمات، وضعیت پنجره، زبان و تم |
| **سیستم آپدیت (Updater)** | Tauri Updater + Local/Remote Adaptor | آپگرید درونی، بررسی روزانه/دستی، چنج‌لاگ پس از ریست |
| **موتور صف و تسک‌ها** | Rust Scheduler + Local SQLite | مدیریت و زمان‌بندی کارهای روزانه، ساعتی و گزارش‌ها |

## ۳. قابلیت‌های کلیدی و نیازمندی‌های ۱۰گانه سیستم

### ۱. سیستم نسخه‌بندی حرفه‌ای (Versioning & SemVer)
- هر نرم‌افزار نسخه اختصاصی خود (`appVersion`) را در `src/app/config.ts` دارد که مستقل از نسخه موتور هسته (`coreVersion`) مدیریت می‌شود.
- سابقه نسخه‌ها در فایل `CHANGELOG.md` یا `releases.json` ثبت می‌شود.

### ۲ و ۳. سیستم آپگرید خودکار و دستی (In-App Updater & Daily Check)
- **دو حالت عملکرد در تنظیمات:**
  1. *دانلود خودکار:* نرم‌افزار در پس‌زمینه نسخه را دانلود کرده و پیام می‌دهد: *"نسخه جدید آماده شد؛ لطفاً نرم‌افزار را ریست کنید."*
  2. *هشدار دستی:* هنگام انتشار نسخه جدید فقط هشدار داده می‌شود و کاربر می‌تواند دستی دکمه دانلود را بزند.
- **بررسی زمان‌بندی‌شده:** یک‌بار در روز به طور خودکار بررسی انجام می‌شود + دکمه "Check for Updates" برای بررسی دستی در صفحه تنظیمات و هدر.
- **معماری قابل انتقال (Local to Cloud):** در حال حاضر اندپوینت آپدیت لوکال است (فایل/لوکال‌هاست) اما ساختار آن طوری پیاده‌سازی می‌شود که با تغییر یک متغیر در کانفیگ، به سرور و وبسایت آنلاین متصل شود.

### ۴. نمایش چنج‌لاگ پس از آپگرید (What's New Modal)
- با ذخیره `last_seen_version` در استور محلی، اگر کاربر بعد از یک آپدیت برنامه را باز کند، به طور خودکار یک مودال تمیز باز شده و ویژگی‌های نسخه جدید (Changelog) را به کاربر نشان می‌دهد.

### ۵ و ۶. تم پیش‌فرض و پشتیبانی دوزبانه (Dark Mode & i18n)
- **تم پیش‌فرض:** دارک مود (`dark`) با قابلیت سوییچ به لایت مود.
- **زبان‌ها:** انگلیسی (پیش‌فرض - LTR) و فارسی (RTL) با لود فونت بهینه‌سازی‌شده لوکال بدون نیاز به اینترنت.

### ۷. موتور صف وظایف و گزارش‌گیری (Task Queue & Scheduler)
- یک بخش جامع در Core برای مشاهده:
  - **کارهای انجام‌شده امروز (Today Completed):** گزارش دقیق زمان و وضعیت موفق/ناموفق.
  - **کارهای در صف (Upcoming / In Queue):** لیست کارهای برنامه‌ریزی‌شده تا انتهای امروز و روزهای آتی.
  - **آرشیو گذشته (History):** مرور تسک‌های روزهای قبل با امکان فیلتر.

### ۸. صفحه تنظیمات (Settings Page)
- صفحه جامع برای تغییر تم، زبان (EN/FA)، نوع آپدیت (خودکار/دستی)، تنظیمات پورت سخت‌افزاری و اطلاعات برنامه.

### ۹. منوی هوشمند سه‌سطحی (3-Level Navigation Hierarchy)
- **سطح ۱:** آیکون‌های درشت در نوار اصلی ناوبری.
- **سطح ۲:** ساب‌منو با آیکون‌های ریز.
- **سطح ۳:** زیرمجموعه‌های متنی بدون آیکون (آکاردئونی یا لیستی).
- ساختار کامپکت: برای اپ‌هایی که تک‌سطحی هستند، ستون‌های اضافی به طور خودکار مخفی می‌شوند تا فضا آزاد بماند.

### ۱۰. هدر مشترک و بخش ابزارهای ثابت (System Header & Profile Menu)
- تمام ابزارهای عمومی و ثابت که در همه اپ‌ها یکسانند از منوی اصلی حذف شده و به **هدر اختصاصی** (سمت راست/چپ کنار تایتل‌بار) منتقل می‌شوند:
  - دراپ‌داون پروفایل
  - دکمه تنظیمات
  - درباره ما (About) و چک کردن آپدیت
  - دکمه خروج کامل از نرم‌افزار

## ۴. ساختار پوشه‌بندی استاندارد (Core vs App)

```text
nora/
├── docs/                           # مستندات پروژه و وضعیت پیشرفت
│   ├── ARCHITECTURE.md             # همین سند (طراحی کلان سیستم)
│   ├── ROADMAP.md                  # فازبندی، تسک‌ها و وضعیت لحظه‌ای
│   └── CONVENTIONS.md              # قوانین کدنویسی و استانداردهای IPC
├── extra docs/                     # مستندات اولیه مرجع (دست‌نخورده تا پایان کار)
│   └── base.md
├── src-tauri/                      # بک‌اند Rust (Tauri 2.0)
│   ├── src/
│   │   ├── commands/               # دستورات IPC با تفکیک وظایف
│   │   │   ├── serial.rs           # فرامین ارتباط سخت‌افزاری و پورت‌های COM
│   │   │   ├── printer.rs          # فرامین چاپگر خام (ESC/POS) و سیستمی
│   │   │   ├── updater.rs          # فرامین بررسی، دانلود و متادیتای آپدیتر
│   │   │   ├── scheduler.rs        # صف و اجرای پس‌زمینه کارهای زمان‌بندی‌شده
│   │   │   └── system.rs           # اطلاعات سیستم، تنظیمات پنجره و اعلان‌ها
│   │   ├── lib.rs                  # رجیستر کردن پلاگین‌ها و کامندها
│   │   └── main.rs                 # نقطه ورود برنامه
│   ├── capabilities/               # مجوزها و Capabilities در Tauri 2
│   ├── tauri.conf.json             # تنظیمات پنجره، ترای و نام برنامه
│   └── Cargo.toml                  # نیازمندی‌های Rust
└── src/                            # فرانت‌اند (React + TS + Tailwind)
    ├── core/                       # [ممنوع برای تغییر در پروژه‌های فرزند]
    │   ├── components/             # تایتل‌بار فریم‌لس، ترای، هدر سیستم، سایدبار ۳سطحی
    │   │   ├── CustomTitlebar.tsx
    │   │   ├── HeaderActions.tsx   # پروفایل، تنظیمات، خروج، درباره ما
    │   │   ├── AppSidebar.tsx      # ناوبری هوشمند سه‌سطحی
    │   │   ├── ChangelogModal.tsx  # مدال نمایش چنج‌لاگ پس از آپگرید
    │   │   └── UpdateBadge.tsx     # نشانگر وضعیت دانلود نسخه جدید
    │   ├── hooks/                  # هوک‌های پایه (useNotification, useUpdater, useScheduler)
    │   ├── services/               # سرویس‌های IPC و بایندرهای Rust به TS
    │   ├── store/                  # استور تنظیمات اصلی (تم، زبان، وضعیت آپدیت و کانفیگ)
    │   └── pages/                  # صفحات مشترک سیستمی (Settings, TaskQueue)
    ├── app/                        # [محل توسعه اختصاصی هر نرم‌افزار]
    │   ├── components/             # کامپوننت‌های بیزینس اپ جدید
    │   ├── pages/                  # صفحات اختصاصی اپ
    │   ├── changelog.json          # تاریخچه تغییرات و متادیتای نسخه‌های این نرم‌افزار
    │   └── config.ts               # کانفیگ مرکزی اپ (نام، نسخه، منوهای ۳سطحی و ...)
    ├── components/ui/              # کامپوننت‌های عمومی Shadcn UI
    ├── App.tsx                     # روتینگ و شل اصلی
    └── main.tsx                    # نقطه ورود ری‌اکت
```
