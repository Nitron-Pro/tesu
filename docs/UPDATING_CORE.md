# راهنمای قطعی به‌روزرسانی هسته نورا در پروژه‌های فرزند (Core Update Guide)

این سند برای تمامی توسعه‌دهندگان و **ایجنت‌های هوش مصنوعی (AI Agents)** نگاشته شده است تا نحوه به‌روزرسانی امن و بدون نقص هسته نورا را در اپلیکیشن‌های مشتق‌شده بیاموزند.

---

## قانون حیاتی بقای پروژه (Critical Rule for AI Agents)
> **هشدار جدی به هر ایجنت:**  
> تحت هیچ شرایطی نباید دستور `git merge` یا `git pull` عمومی بر روی پروژه فرزند اجرا شود؛ زیرا پوشه `src/app/` پروژه فرزند حاوی منطق بیزینسی، صفحات و فرم‌های اختصاصی آن اپلیکیشن است و هرگونه مرج کورکورانه موجب تداخل (Conflict) یا حذف کدهای اختصاصی نرم‌افزار جدید می‌شود.  
> **تنها روش استاندارد و مجاز گیت برای آپدیت هسته، روش زیر (Git Selective Checkout) است.**

---

## روش استاندارد گیت: Selective Checkout (روش مصوب شماره ۱)

در این روش، پروژه فرزند دارای یک **مخزن گیت محلی کاملاً مستقل** است و پروژه بویلرپلیت مادر (`nora`) تنها به عنوان یک ریموت محلی (Local Remote) فقط‌خواندنی به آن متصل می‌شود. از آنجا که به جای دستور `merge` از دستور `checkout -- path` استفاده می‌شود، هیچ تداخل شاخه‌ای (Conflict) رخ نخواهد داد و **فقط فایل‌های هسته** بدون آسیب رساندن به `src/app/` استخراج و اعمال می‌گردند.

### پیش‌نیاز (در زمان ساخت پروژه جدید - تنها یک بار)
پروژه فرزند را با گیت مستقل خود راه‌اندازی کرده و نورا را متصل کنید:
```bash
git init -b main
git remote add core E:/projects/nora
git add .
git commit -m "feat: initial commit of new app"
```
*(از این به بعد آزادانه روی پروژه جدید کار کنید و کامیت‌های اختصاصی خودتان را بزنید).*

---

### مرحله ۱: دریافت آخرین لیست تغییرات از پروژه مادر لوکال
هنگامی که هسته نورا در `E:/projects/nora` آپدیت شد:
```bash
git fetch core
```
این دستور کدهای جدید هسته را از روی هارد سیستم در کش لوکال گیت پروژه فرزند می‌خواند (کاملاً آفلاین و سریع) بدون اینکه به کدهای شما دست بزند.

---

### مرحله ۲: استخراج و جایگزینی فایل‌های هسته (دستور طلایی)
با این دستور، گیت **فقط و فقط** فایل‌ها و پوشه‌های لایه زیرساخت و هسته را از شاخه `core/main` می‌خواند و در پروژه جاری جایگزین می‌کند:

```bash
git checkout core/main -- src/core src/components/ui src-tauri .cursor docs scripts package.json
```

#### چرا این دستور ۱۰۰٪ ایمن و بدون تداخل است؟
1. **عدم انجام ادغام (No Merge):** دستور `checkout -- path` یک دستور Copy هوشمند بر مبنای Git Tree است و شاخه‌ها یا کامیت‌های دو پروژه را ادغام نمی‌کند تا کانفلیکتی رخ دهد.
2. **پوشه `src/app/` دست‌نخورده می‌ماند:** چون `src/app/` در لیست این دستور نیست، تمام صفحات، منوها، شناسنامه و بیزینس اپ شما کاملاً محفوظ می‌ماند.
3. فایل‌های `src-tauri/`، درایورهای سخت‌افزاری Rust، سرویس‌های ترای و تایتل‌بار به آخرین نسخه ارتقا می‌یابند.
4. تمام تغییرات هسته مستقیماً به عنوان فایل‌های استیج‌شده (Staged) در گیت پروژه جدید قرار می‌گیرند.

---

### مرحله ۳: نصب وابستگی‌ها و تست بیلد
پس از دریافت فایل‌های جدید هسته:
```bash
# نصب پکیج‌های احیاناً جدید
npm install

# تست بیلد تایپ‌اسکریپت و استاتیک
npm run build
```

---

### مرحله ۴: ثبت کامیت آپدیت در گیت پروژه فرزند
```bash
git add .
git commit -m "chore: sync core engine with latest nora vX.Y.Z"
```

---

## خلاصه دستورات برای ایجنت (Cheatsheet for AI Agent)
```bash
# 1. Fetch updates from local core repo
git fetch core

# 2. Checkout core-only paths (never include src/app/)
git checkout core/main -- src/core src/components/ui src-tauri .cursor docs scripts package.json

# 3. Verify & install
npm install
npm run build

# 4. Commit update in child project repo
git add .
git commit -m "chore: update nora core framework"
```
این فرآیند تضمین می‌کند پروژه‌های جدید برای همیشه از آخرین ارتقاها و پچ‌های امنیتی هسته نورا بهره‌مند شوند، بدون اینکه کدهای برنامه اختصاصی مخدوش گردد.
